2. Reboot the phone once so the queued module update can take effect.
3. Open Cyclone Cloak and run Root Doctor again.
4. If it still reports Zygisk status unknown, inspect the app logs for CloakRootDoctor and CLOAK_DOCTOR=ZYGISK_STATUS_UNKNOWN.
5. The exact root cause we found is that Magisk returns alue=1, while the app expected the plain value 1. The patch in CloakRootDoctor.kt now strips the alue= prefix before the comparison.
