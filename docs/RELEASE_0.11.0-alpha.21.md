## Upgrade and limits

Update with the existing signed APK. Existing profiles, engine records and version
1 plans are not migrated or rewritten. Schema 0.2/0.3 profiles are read-only in
Studio. Locks and unsaved edits are editor-local. Fixed hardware cannot become
diverse through reseeding; more varied drafts require distinct catalog templates.
Unknown facts do not earn diversity credit. Repair cannot fill facts missing from
the compatible catalog. Existing hash-bound evidence/engine metadata may become
stale after edits, and publication is not automatically refreshed.

No production runtime hooks, connector, binding, publication, storage layout,
profile schema, permissions or module behavior changes. Only module packaging
metadata changes. No networking, account/SMS functions or platform verdict claims.
Physical Studio/workshop interaction is **UNVERIFIED**; older attached diagnostics
evidence does not verify this new UI. No physical-device test was run.
