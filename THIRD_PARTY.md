# Third-party components

## Pine (runtime hook engine)

- Artifact: `top.canyie.pine:core` (Maven Central), vendored into the module zip at build time.
- Upstream: https://github.com/canyie/pine
- License: Anti-996 License v1.1 (https://github.com/996icu/996.ICU/blob/master/LICENSE)
- Used for: in-process Java framework callbacks (telephony identity, ANDROID_ID, Wi-Fi and
  Bluetooth addresses, device serial) inside scoped apps.
