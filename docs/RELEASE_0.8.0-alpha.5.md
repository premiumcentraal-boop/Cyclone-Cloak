# Cyclone Cloak 0.8.0-alpha.5

Makes saved device identities easier to review and manage:

- Groups each identity's device model, build, generated identifiers, SIM and network, display, and locale details.
- Lets users expand an identity to inspect and copy individual values.
- Clarifies which identity and Cyclone profile are selected before binding.
- Keeps the existing fleet creation, import, export, and binding flows.
